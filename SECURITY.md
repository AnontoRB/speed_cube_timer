# Security Policy

## Supported versions

Only the latest version of CubeTimer (the current `main` branch) receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the repository, go to the **Security** tab and choose **Report a vulnerability**. Include what you found, the steps to reproduce it, and which part is affected (website, `server.js`, `worker.js` or `admin.html`).

You can expect a first answer within 7 days. If the report is accepted, a fix is made as soon as possible and you are told when it is published. If it is declined, you get a short explanation of why.
